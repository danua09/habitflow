# HabitFlow

Курсовой проект «Платформа для управления персональными целями и привычками (трекер привычек)». Flask, Jinja, JavaScript, PostgreSQL и SQLAlchemy.

## Локальный запуск на Windows

Установите Python 3.13 и PostgreSQL 17, запустите службу PostgreSQL. В PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python setup_postgres.py
python run.py
```

`setup_postgres.py` создаёт отдельную пустую базу `habitflow` и запрашивает пароль локального пользователя `postgres`. Если DATABASE_URL уже задан в `.env`, повторно этот скрипт запускать не нужно. Приложение доступно по адресу http://localhost:5050. Пароли и `.env` в репозиторий не добавляются.

Для существующей настроенной базы миграции и список достижений применяются командами `python -m flask --app run db upgrade` и `python seed.py`. Применение начальной миграции к уже заполненной базе без версии Alembic требует отдельной проверки.

Для отдельного демонстрационного аккаунта: `python seed.py --demo`. Скрипт запросит пароль, создаст аккаунт `demo@example.com` с примерами и не перезапишет существующий аккаунт. В текущей локальной установке демонстрационный аккаунт уже создан; данные входа записаны в игнорируемом Git файле `.demo-credentials`.

## Docker

Задайте переменные окружения `POSTGRES_PASSWORD` и `SECRET_KEY`, затем выполните `docker compose up --build`. Контейнер приложения применит миграции и запустится на http://localhost:5000; база хранится в томе `db-data`. Docker-конфигурация подготовлена, но запуск контейнеров в текущем окружении не проверялся.

## Тесты

`python -m pytest -q` использует изолированную SQLite в памяти. Для PostgreSQL тестовая конфигурация допускает только отдельную базу с именем `habitflow_test_<32 hex символа>`, указанную в `HABITFLOW_TEST_DATABASE_URL`; тесты удаляют таблицы в этой базе. Не указывайте рабочую базу.

## Расчёт

Процент привычки — доля выполненных запланированных дней с даты её создания в выбранном периоде. Серия учитывает только запланированные дни и сохраняется в течение текущего дня до его завершения. Прогресс цели показывает долю выполненных запланированных действий связанных привычек с даты создания цели; завершение цели отмечается вручную. При изменении расписания прежняя версия сохраняется для прошлых дат; сведения об изменениях, сделанных до внедрения истории, восстановить нельзя.

## Восстановление пароля и электронная почта

Отправка отключена, пока не настроен почтовый сервис. Локально можно использовать Gmail SMTP с TLS на порту 587: задайте `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_USERNAME` и пароль приложения в `SMTP_PASSWORD`. Бесплатный Render блокирует SMTP-порты, поэтому для него предусмотрен Resend: `EMAIL_PROVIDER=resend`, `RESEND_API_KEY` и `MAIL_FROM` (проверенный адрес отправителя). Для опубликованного сайта `PUBLIC_BASE_URL` должен содержать его HTTPS-адрес. Учётные данные не добавляются в Git. Письма о событиях отправляются только пользователям, включившим эту возможность в профиле. Напоминания по расписанию и push-уведомления не реализованы.
